Анализ графа Эрдеша–Реньи

Основная цель работы заключается в построении графа с заданными параметрами и сравнении экспериментального значения средней степени вершины с теоретическим.


Генерируется случайный граф со следующими параметрами:
- n = 42 вершины
- p = 0.65 вероятность появления ребра между любой парой вершин

Каждая возможная пара вершин рассматривается независимо. Ребро между ними появляется с вероятностью p.

Граф генерируется с использованием библиотеки NetworkX и модели Эрдеша–Реньи.

После генерации графа:
1. Вычисляется степень каждой вершины.
2. Находится средняя степень как среднее значение по всем вершинам.
3. Вычисляется теоретическое значение средней степени по формуле:

средняя степень = p * (n - 1)

Обоснование формулы:

Каждая вершина потенциально может быть соединена с (n - 1) другими вершинами, так как связь вершины самой с собой не рассматривается.

Для каждой из этих возможных связей вероятность появления ребра равна p.

Следовательно, ожидаемое количество связей одной вершины (то есть ее средняя степень) определяется как произведение p на (n - 1).


Программа выводит:
- экспериментальное значение средней степени
- теоретическое значение
- разницу между ними


Теоретическое значение является ожидаемым, тогда как экспериментальное получается для одной конкретной реализации случайного графа. Из-за случайности фактическое число ребер может незначительно отличаться от ожидаемого.

Используемые технологии:

- Python
- NetworkX
